# Public offline tests

Run on Windows with Python 3.13:

```powershell
python -m pip install -r tests/requirements-ci.txt
python tests/run_offline.py
```

The runner isolates settings, history and cache in a fresh temporary directory,
clears inherited application credentials, and rejects real Python socket and
subprocess operations. API traffic, process creation, audio output and Viewer
messages in these tests use mocks. The suite requires no API secret, Steam,
Live2DViewerEX, game installation, model weights, microphone or GPU.

Missing private assets are not counted as a successful character acceptance.
Thirteen tests are explicitly skipped because they require excluded portrait
layers, a full private-resource distribution, the omitted legacy entry point,
or real loopback/7-Zip integration. Additional platform-dependent tests may be
skipped when their operating-system capability is unavailable. The report prints each skipped case and its
reason. The share-voice launch/cleanup tests use a generated four-second tone
and a synthetic transcript, not the character recording.

`test_public_asset_boundaries.py` uses only generated bytes and metadata. It
checks that absent, modified, relabelled or out-of-directory scene evidence
cannot be injected into a conversation. Passing structural fixtures does not
establish original-game dialogue accuracy or visual source review.

This is a selected regression suite, not the complete upstream test archive.
Local extraction/research tools, their private-fixture tests, and a stale
platform-wide architecture assertion are excluded. CI does not certify an
exported character model, speech timbre, CUDA compatibility, real service
access, or a complete distributable build.
